# 风格规范

## 色彩
| 用途 | 色值 |
|---|---|
| 底色（三选一） | 深蓝 #16213a → #07080d 径向渐变 / 深棕 #2a1c14 / 近黑 #07080d |
| 金色强调 | #E6C27A |
| 品牌红强调 | #C8102E |
| 字幕主色 | 米黄 #F5E9D3 |

## 字体
- 衬线粗体（字重 900）：宋体-简 Songti SC / 华文宋体 STSong / Noto Serif CJK SC / 思源宋体。只写名称，使用者自行安装，本包不附带字体文件。

## 版式
- 字幕：底部居中，距底 70px，字号 62px，单行，上方有 230px 黑色渐变压底。
- 章节标签：左上角金边胶囊，46px。
- 主体：画面中上部，下方约 1/4 留给字幕。
- 封面 3:4（1080×1440）：三行大字（白 / 金 / 红，红行最大）+ 底部副标题与金色短线；首帧版本缩放 0.75 居中放进 1920×1080。

## 动态
- 背景常驻：透视金色地面网格滚动 + 60 个漂浮光点，保证任何时刻不静止。
- 场景切换淡入 8 帧 / 淡出 6 帧；字幕淡入 6 帧并上移 16px。
- 每个场景至少一个持续动作（人物晃动、特效循环、道具变化），约 3 秒换一个画面状态。

## 造型
- 2D 扁平几何人物（圆头、圆角身体），表情 5 种；不用写实照片、真人、第三方插画。

## 禁止
- 正文出现标题、水印、联系方式、二维码、导流信息；人声、配音、片内音乐。
