# 自检清单（抽帧检查）

先跑 `bash scripts/qc.sh final.mp4`（自动检查前 4 项），再看 `qc/contact.jpg`（每秒一帧）逐项核对：

- [ ] 总时长 15–30 秒（自动）
- [ ] 分辨率 1920×1080，横屏铺满，无黑边（自动 + 目检）
- [ ] 无音轨、无人声（自动）
- [ ] 第一帧是 3:4 封面、持续约 0.01 秒，标题清晰可读（自动 + 看 f000_cover.jpg）
- [ ] 字幕在下方居中，每句 2.6–3.6 秒，没有两句重叠、没有出画
- [ ] 关键词已标金/红，字幕不被画面元素遮挡
- [ ] 每个场景都在动，没有超过 3 秒的完全静止画面
- [ ] 底色为黑/深棕/深蓝，强调色只有金和红
- [ ] 正文画面没有标题、水印、联系方式、二维码
- [ ] 前 3 秒有钩子；全片只有一个核心机制；没有给解决方法
- [ ] 结尾有「选 1 还是 2」互动题
- [ ] 查不到出处的数据已写成「有研究发现」；无错别字
